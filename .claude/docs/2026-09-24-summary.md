## Problems found in real runs

- **The model invents prices from text:**
  - a "change details before 01/10" deadline came back as an Early Bird tier;
  - a photo package came back as "Standard 99,000".
- **Posters print no year.** The model wrote 2023 for a 2027 race.
- **ActiUp quirks:**
  - the API answers in English unless `Accept-Language: vi`;
  - finished events are marked `sold_out`;
  - the organizer field is sometimes a paragraph;
  - one event appears twice in the listing.
- **VnExpress pages carry a menu of every edition.** Without cutting it out, every race would look changed whenever a new race is added.
- **Antigravity** left scratch files in the repo root (removed), and a stray edit to its JSON was reverted.
