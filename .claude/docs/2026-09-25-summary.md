## Problems found in real runs

- **The model invents an audience:** every Sơn Trà price came back "Resident"; every Bắc Ninh price was repeated for Resident and Non-resident. The prompt had told it to split by runner.
- **It computes prices:** Quảng Trực's group discounts are only percentages. The model worked out prices from them, and got some wrong (616,050 for 616,550).
- **Combos and relay teams** came back as the distance or audience, so they looked like single entries. They'd have given a wrong "from" price.
- **Made-up dates:** a poster with no dates read as "07/07 - 10/01" (10/01 is race day).
- **Posters print impossible days** (Tết Run: "31/11/2026").
- **A wide, busy image shifts rows** (Vũng Tàu: each distance got the next row's prices, and a slogan became a tier). No rule catches it, and a better prompt didn't help.
- **A poster can show only one day of a two-day race:** Vũng Tàu City Trail's price poster says 29.11.2026, but the race runs 28–29/11 (user confirmed), as ActiUp's API says. A date override to the 29th was made by mistake and removed (0d459c2, bb681dc, reverted by 1e836f0 and 0567c94).
