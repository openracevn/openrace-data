- New `CourseSchema`:
  ```ts
  z.object({
    label: z.string().refine(isDistance, "not a distance"), // "21km", "Sprint", "70.3"
    meters: z.number().int().positive().nullable(),         // null: unknown (e.g. "Kids")

  })
  ```
- New `GeoSchema`, the whole field `.nullable()` (null = not located yet, or a virtual race):
  ```ts
  z.object({
    lat: z.number().min(8).max(24),      // Vietnam's bounding box
    lng: z.number().min(102).max(110),
    source: z.enum(["maps_link", "nominatim", "manual"]),
    precision: z.enum(["venue", "ward", "province"]),
    current: z.object({ province: z.string().regex(/^\d{2}$/), ward: z.string().regex(/^\d{5}$/).nullable() }),
    legacy: z.object({ province: z.string().regex(/^\d{2}$/), district: z.string().regex(/^\d{3}$/).nullable(), ward: z.string().regex(/^\d{5}$/).nullable() }).nullable(),
    access: z.enum(["road", "flight_or_ferry"]),
    // Keyed by place id from config/places.yaml. km: driving km, or straight-line km when method is "straight_line".
    fromPlaces: z.record(z.string(), z.object({ km: z.number().nonnegative(), minutes: z.number().int().nonnegative().nullable(), method: z.enum(["road", "straight_line"]) })),

  ```

### A3. `courseMeters(label)` in `scripts/lib/schema.ts`

| label | meters |
|---|---|
| `"10km"`, `"21km"`, `"42km"`, `"1.5km"` | 10000, 21000 → **21097**, 42000 → **42195**, 1500 |
| `"750m"` | 750 |
| `"100mi"` | 160934 (round(n × 1609.344)) |
| bare number `"56.50"`, `"56.5"` | 56500 (km) |
| `"Super Sprint"` | 12900 |
| `"Sprint"` | 25750 |
| `"Olympic"`, `"Standard"`, `"5150"` | 51500 |
| `"70.3"`, `"Half"` | 113000 |
| `"140.6"`, `"Full"` | 226000 |
| `"Kids"` | null |

`"21km"` and `"42km"` are how normalization writes a half and a full marathon, so they map to the real distance. `"70.3"` and `"140.6"` are named formats even though they look like numbers: check them before the bare-number rule. Named formats are case-insensitive. Anything else → `null`.

### A4. `scripts/lib/reconcile.ts`: courses, edition, tier windows

- `fields.courses`: the first usable source with a non-empty `courses` (same rule as `distances` today). Then, for any course whose `type` or `elevationGain` is `null`, take it from another usable source's course with the same label.
- The distances-disagree flag compares course labels (same wording, `courses` instead of `distances`).
- `fields.edition`: `first((f) => f.edition)`.
- `fields.geo`: `null` (Stage C fills it).
- `fields.prices`: after collecting every source's tiers, run `fillTierWindows(prices, fields.date)`, exported from `reconcile.ts`:
  - A **ladder** is the tiers sharing `site`, `distance` and `audience`, with `kind` in `super_early | early | regular | late`. `group` and `other` tiers are never changed.
  - Order a ladder by kind (super_early → early → regular → late), then by `from` (null first), then by `to` (null last).
  - For each tier in order: a null `from` becomes the day after the previous tier's `to` (only if the previous tier has a `to`); a null `to` becomes the day before the next tier's `from` (only if the next tier has a `from`); the last tier's null `to` becomes race day.
  - Never produce `from > to`: if a filled value would, leave that value null.
  - Each filled value adds `"from"` or `"to"` to `inferred`, in that order. Tiers you don't touch get `inferred: []`.
  - The output keeps the input order of `prices` (only the values change).
- `applyOverrides` is unchanged. An override value is served as written.
